# Module Life

## Overview

Module Life is a multiparameter biogeochemical module based on ERSEM. It is a more complex model than [Module WaterQuality](waterquality.md) and is able to simulate nutrients (nitrogen, phosphorus and silica biogeochemical cycles) along with several primary producers, secondary producers and decomposers in the water column. Variable N:P:C ratios in each type of organism are also computed.
