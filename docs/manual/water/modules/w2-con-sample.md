# W2 con sample

This page lists the keywords of a CE-QUAL-W2 `w2_con.npt` file that must be changed from the Beliche reference run (`\\Datacenter\Albufeiras_Eutrofizacao\ComoFazer\2.CorreCe-Qual\ExemploFeito_Beliche\1.SimulacaoZero\AdaptedToW2con`) to suit a new reservoir geometry.

## Useful recommendations

1. Use the *Cin_br1.npt*, *Tin_br1.npt* and *Qin_br1.npt* files from the Beliche run and replicate them for every branch.
2. Use the *shd.npt* and *wsc.npt* files generated by the w2i geometry software.
3. Then, edit the *wsc.npt* file and alter the ending date to 1000 days.
4. Alter the *w2_con.npt* from the Beliche run according to your watershed geometry.

## Sample file

Leave only one blank line between the last of your branches and the next parameter line: extra blank lines can cause the model to crash.

The excerpts below are the non-contiguous blocks of the reference `w2_con.npt` that must be edited; each block is identified by its line numbers in the reference file.
