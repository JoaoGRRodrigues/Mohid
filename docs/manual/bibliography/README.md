## How to cite MOHID

Cite the main description of the modelling system and the paper for the specific
module you used. Entries include journal, volume, pages and, when available, a DOI.

## Adding a publication

Journal articles go to the page for their publication year; conference papers,
theses and reports go to their own pages. Keep the style of the neighbouring entries.
