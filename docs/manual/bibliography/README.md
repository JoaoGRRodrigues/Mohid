## How to cite MOHID

When citing the modelling system itself, reference the main description of the
system and the specific module paper for the process you used. The entries in
these lists include the journal, volume, pages and, where available, a DOI link.

## Adding a publication

Add the reference to the matching page, keeping the style of the neighbouring
entries: authors, title, journal, year, volume(issue), pages, and a DOI or URL
when available. Journal articles go to the page for their decade; if you are
unsure, open an issue in the repository instead of guessing.
