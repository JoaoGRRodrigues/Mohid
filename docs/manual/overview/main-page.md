# MOHID

MOHID is short for *Modelo Hidrodinâmico* (hydrodynamic model). It is a three-dimensional
water modelling system developed by MARETEC (Marine and Environmental Technology Research
Center) at Instituto Superior Técnico, University of Lisbon, and applied to estuaries,
coastal seas, reservoirs and watersheds.

The system is modular: MOHID Water and MOHID Land share the same base libraries, and a set
of pre- and post-processing tools supports model setup and analysis.
